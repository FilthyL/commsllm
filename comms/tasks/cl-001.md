## Goal
Make the Lead hear about every new PR and goal issue without the owner relaying anything. Make the label set in `comms/labels.json` exist on the repo. This closes the last manual step of Phase 0.

## Acceptance criteria
- [ ] `.github/workflows/comms-announce.yml` runs on `pull_request` (`opened`, `reopened`, `ready_for_review`) and on `issues` (`opened`, `labeled`).
- [ ] It resolves the bus PR as follows. Take `bus_pr` from `comms/config.yml` if it is non-zero, read with a small inline shell/awk or Python stdlib snippet, not a third-party action. Otherwise look up the open PR whose head branch is `comms/bus` (`gh pr list --head comms/bus --state open --json number`). If there is no bus PR, or the event is on the bus PR itself, it exits 0 without posting.
- [ ] For a PR it posts this on the bus PR, using `gh` with `GITHUB_TOKEN`:
      `COMMS/1 type=notify from=router to=claude task=<id-from-title-or-bus> pr=#<n> next=claude`
      followed by one line with the PR title, the author login and a link. `<id>` is parsed from a `[cl-N]`/`[cx-N]` title prefix, or `bus` if there is none.
- [ ] For an issue, it posts only when the issue has the `goal` label, with `task=goal-<n>`.
- [ ] The PR title, issue title and body are passed through `env:` and never interpolated into `run:` scripts. That prevents script injection.
- [ ] `permissions:` is minimal: `contents: read`, `pull-requests: write`, `issues: write`.
- [ ] `.github/workflows/comms-labels.yml` runs on `push` to `main` that touches `comms/labels.json`, and on `workflow_dispatch`. It creates or updates every label with `gh label create --force`. It never deletes labels.
- [ ] Both workflows pass `actionlint`.

## Verify
```bash
# actionlint (download the binary if it isn't installed; https://github.com/rhysd/actionlint)
actionlint .github/workflows/comms-announce.yml .github/workflows/comms-labels.yml   # → no output, exit 0
# after merge (done by the Lead): run comms-labels via workflow_dispatch → the labels exist;
# open any PR → a notify comment appears on the bus PR (TRANSPORTS T5)
```

## Out of scope
- Routing or dispatching agents (cl-004). CI (cl-002). Creating the bus PR itself (the Lead does that).

## Notes
- `gh` is preinstalled on GitHub-hosted runners. Set `GH_TOKEN: ${{ github.token }}`.
- Comments made with `GITHUB_TOKEN` don't trigger other workflows. That's fine here.
- Don't push to the bus PR branch, ever.
