## Goal
One command installs this collaboration system into any other repo of the owner's, so new projects start in Phase 1 right away.

## Acceptance criteria
- [ ] `scripts/install-kit.sh <target-repo-dir> [--force]` copies `AGENTS.md`, `CLAUDE.md`, `docs/PROTOCOL.md`, `docs/ARCHITECTURE.md`, `comms/config.yml` (with `bus_pr: 0` and `phase: 1`), `comms/labels.json`, `comms/TRANSPORTS.md`, `comms/LESSONS.md`, `comms/decisions/0001-*`, `comms/tasks/_TEMPLATE.md`, `scripts/comms.py`, `scripts/router.py`, `scripts/ci.sh`, `.github/pull_request_template.md`, `.github/ISSUE_TEMPLATE/goal.yml` and every `.github/workflows/comms-*.yml`, `ci.yml`, `*-agent.yml`.
- [ ] It does **not** copy `comms/tasks/cl-*` or `cx-*`.
- [ ] It refuses to overwrite an existing file unless `--force`, and lists what it skipped.
- [ ] It prints the owner checklist when it finishes: commit and open a PR, connect Codex cloud to the repo, give Claude access, add the secrets, create the bus PR.
- [ ] `tests/test_install_kit.py` installs into a temp `git init` repo, then runs `python3 scripts/comms.py lint` there successfully.

## Verify
```bash
python3 -m unittest tests/test_install_kit.py -v   # → OK
shellcheck scripts/install-kit.sh                  # → clean
```

## Out of scope
- Creating remote repos, or pushing anywhere.
