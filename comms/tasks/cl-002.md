## Goal
Every PR gets one required check, `ci`, that finishes in under 3 minutes. Later tasks extend `scripts/ci.sh`, never the workflow, so lanes don't conflict on the workflow file.

## Acceptance criteria
- [x] `.github/workflows/ci.yml` has a single job with id and name `ci`. It runs on `pull_request`, `push` to `main` and `workflow_dispatch`, with `permissions: contents: read`, and its only step after checkout is `bash scripts/ci.sh`.
- [x] Concurrency group per ref, with `cancel-in-progress: true`.
- [x] `scripts/ci.sh` (`set -euo pipefail`) runs, in order and skipping whatever is absent:
      1. `actionlint` on `.github/workflows/*.yml` (installs the pinned release binary if it's missing);
      2. `shellcheck` on `scripts/**/*.sh` (preinstalled on ubuntu runners; skip with a warning if it's absent locally);
      3. `python3 -m json.tool comms/labels.json`;
      4. `python3 -m unittest discover -s tests -v` if `tests/` exists;
      5. `python3 scripts/comms.py lint` if `scripts/comms.py` exists.
- [x] Each step prints a `== step ==` banner, and the script exits non-zero on the first failure.
- [x] Runs locally in a clean checkout with only python3 and bash, by skipping the tools that are missing.

## Verify
```bash
bash scripts/ci.sh          # → all present steps pass, exit 0
shellcheck scripts/ci.sh    # → clean
```

## Out of scope
- Branch protection. That's a human gate: the owner makes `ci` required.
- Any language toolchains for future projects. Those projects add their own steps to `ci.sh`.

## Implementation evidence
- `bash scripts/ci.sh`: passed; downloaded actionlint v1.7.7 and verified its official release checksum; workflow lint and labels JSON passed.
- `shellcheck scripts/ci.sh`: unavailable locally (command not found); CI runs it on Ubuntu when installed.
- Failure propagation and minimal local-tool behavior verified with temporary PATH shims outside the repository.

## Assumptions
- Missing optional local bootstrap tools or unsupported actionlint platforms warn and skip; attempted downloads and failed checks remain fatal.
- Tests and comms lint are skipped until their files exist.
