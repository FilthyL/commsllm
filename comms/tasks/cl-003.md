## Goal
A single stdlib-only Python 3.10+ tool that both agents and the workflows use, so messages and task files are always well-formed. It removes a whole class of protocol errors and round-trips.

## Acceptance criteria
- [x] `scripts/comms.py` uses only the stdlib, is runnable as `python3 scripts/comms.py <cmd>`, and has `--help` with an example for each subcommand.
- [x] `msg --type T --from F --to X --task ID --next N [--round R] [--verdict V] [--re CID] [--body-file PATH|-]` prints a full comment. That's an `@codex` line when `to=codex` and `codex_runner: cloud`, or an `@claude` line when `to=claude` and `claude_runner: action`, then the header, then the body. It validates enum values against PROTOCOL §1–3 and exits 2 on invalid input.
- [x] `parse [PATH|-]` reads a comment body and prints the **last** `COMMS/1` header as JSON (`{}` and exit 1 if there is none). It ignores unknown keys but keeps them in the output.
- [x] `lint` validates `comms/config.yml` (required keys, enums) and every `comms/tasks/*.md` except `_TEMPLATE.md`. Each task file needs the required front-matter keys and valid enums, an `id` that matches the filename, a non-empty `scope`, `depends_on` IDs that exist, and the body sections `## Goal`, `## Acceptance criteria`, `## Verify`. Errors print as `path:line: message`. Exit 1 if there are any.
- [x] `new --title "..." [--owner codex] [--prefix cl|cx]` creates the next free `comms/tasks/<prefix>-<n>.md` from `_TEMPLATE.md` with `status: draft`, and prints its path.
- [x] `board` prints a Markdown table of the tasks (id, title, status, owner, size, depends_on), grouped by status.
- [x] The parser for the restricted YAML subset (PROTOCOL §5: scalars, inline lists, block lists, `#` comments) is implemented and tested. Nested maps get a clear error.
- [x] `tests/test_comms.py` (unittest) covers: header round-trip (msg → parse), last-header-wins, unknown keys, invalid enums, lint passing on the repo's real files, lint failing on fixtures (bad id, missing scope, unknown dependency), mention rules for both runner settings, and `new` picking the next free number.

## Verify

## Out of scope
- Calling the GitHub API. The workflows wrap this CLI with `gh`.
- PyYAML or any other third-party dependency.
